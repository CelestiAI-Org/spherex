# Intro voice lines

Optional recordings for the intro. Put them here as `line1.mp3` to `line5.mp3` and list each file
you added in `voice.json`, for example `{ "files": ["line1.mp3", "line2.mp3"] }`. Lines not listed
are skipped (no request is made) and their captions still show. See "Voiceover" in
`web/PlanetX/SCENE.md`.
